# 팔자언니 (palja-unnie)

대구 MZ 무당 언니가 봐주는 모바일 사주 웹앱.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Path | Description |
|------|-------------|
| `/` | 모바일 홈 (캐릭터 + CTA) |
| `/consult` | 상담 진입 플레이스홀더 |

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
